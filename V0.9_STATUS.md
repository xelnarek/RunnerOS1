# RunnerOS V0.9 Status

## Implemented
- Real web GPS with high accuracy and filtering
- Real Android FusedLocationProviderClient foreground service foundation
- Native Capacitor location events + persistent Android buffer
- Recovery of interrupted sessions
- Auto-pause / auto-resume
- Moving time / improved segment validation / splits
- GPS quality UI
- Training load / recovery / consistency / 8-week mileage chart
- Health Connect native plugin: availability, permissions, activity/distance write, heart-rate read
- Premium training UI updates

## Not physically verified in this environment
- 30–60 minute outdoor GPS test on a real Android phone
- screen-off/background GPS behavior on a specific OEM
- real BLE heart-rate sensor
- end-to-end Google Play release signing

## Known limitation
Map matching is not implemented in V0.9 because it requires an explicit routing/map provider and license/usage configuration. The GPS quality engine deliberately does not pretend that straight-line filtering equals map matching.
