# RunnerOS — roadmapa techniczna

## V0.2 — DONE SOURCE STAGE
GPS quality, pause/resume, moving time, splits, activity detail, GPX/JSON export, local persistence.

## V0.3 — MAP + DURABLE OFFLINE
IndexedDB, MapLibre, session recovery, map trace, SVG charts.

## V0.4 — ANDROID CORE
Capacitor, foreground service, background location, Android permissions, notifications, battery handling.

## V0.5 — HEALTH + SENSORS
Health Connect, BLE heart rate, cadence, device metadata.

## V0.6 — ROUTES
Route Builder, saved routes, GPX route import, route elevation profile, offline route cache.

## V0.7 — SEGMENTS
Segment matching, PB, local leaderboard, segment history.

## V0.8 — SOCIAL
Accounts, followers, feed, likes/kudos, comments, clubs, privacy controls.

## V0.9 — ANALYTICS
Training load, HR zones, PB detection, fitness trend, recovery, race prediction.

## V1.0 — AI COACH
Personalized analysis, workout feedback, adaptive goals, training recommendations, natural-language summaries.
