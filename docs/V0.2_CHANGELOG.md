# RunnerOS V0.2 — Changelog

## Krytyczne poprawki
- Pause nie zatrzymuje już tylko zegara UI: zatrzymuje zapis GPS i odejmuje czas pauzy od moving time.
- Zapis aktywności zawiera durationSec, movingSec i pausedSec.
- Tempo korzysta z moving time.
- GPS odrzuca punkty o bardzo złej dokładności oraz nierealistyczne skoki.
- Koniec treningu zapisuje pełny ślad i metryki.

## Funkcje
- splity 1 km,
- max speed,
- activity detail,
- GPX export,
- JSON export,
- delete activity,
- PWA manifest.

## Decyzja architektoniczna
PWA pozostaje główną warstwą UI. Android będzie miał osobny moduł natywny dla foreground/background GPS, Health Connect, BLE i powiadomień.
