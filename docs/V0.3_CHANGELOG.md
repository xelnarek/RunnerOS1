# RunnerOS V0.3

## Najważniejsze zmiany
- lokalny auto-save aktywnej sesji GPS,
- odzyskiwanie niedokończonego treningu po odświeżeniu/zamknięciu PWA,
- odrzucenie odzyskanej sesji,
- wizualny podgląd śladu GPS bez zewnętrznej biblioteki map,
- rozbudowany Activity Detail,
- zachowanie offline-first.

## Następny etap
V0.4: MapLibre, prawdziwa mapa, Android foreground location service, Capacitor, Health Connect i testy GPS.
