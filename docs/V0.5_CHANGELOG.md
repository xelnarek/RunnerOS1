# RunnerOS V0.5

## UI/UX
- Premium dark visual system with stronger hierarchy, spacing and cards.
- Clearer running CTA and high-contrast live metrics.
- Improved bottom navigation, activity history, profile and detail views.
- Accent system based on a restrained lime highlight for active states and actions.

## Android preparation
- NativeLocationBridge remains isolated behind a stable contract.
- Added implementation notes for Capacitor Foreground Service integration.
- Next release will connect the bridge to Android foreground location rather than changing the PWA activity engine.

## Quality rule
- Visual polish does not replace functional verification. The project must be built and tested after dependency installation in CI or AI Studio.
