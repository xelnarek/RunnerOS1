# RunnerOS V0.8

- Podłączono natywny FusedLocationProviderClient do Capacitor pluginu.
- RunnerLocationService działa jako foreground service typu location.
- Punkty GPS są buforowane po stronie Androida jako warstwa odzyskiwania.
- WebView otrzymuje eventy `location` ze źródłem `android`.
- RecordScreen wybiera native plugin na Androidzie i web geolocation poza Androidem.
- Dodano analitykę 7/30 dni, regularność i najlepsze średnie tempo.
- Ulepszono hierarchię UI, karty analityczne i oznaczenie wersji.
- Zwiększono versionCode do 8 / versionName 0.8.0.

## Ważne
Pakiet zawiera kod natywny, ale poprawność terenową musi zostać potwierdzona na fizycznym telefonie.

- Dodano czyszczenie bufora natywnego przy rozpoczęciu nowego treningu, aby punkty poprzedniej sesji nie mieszały się z nową.
