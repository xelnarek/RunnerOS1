# RunnerOS V0.9 — GPS Quality + Auto Pause + Analytics + Health Connect

## Najważniejsze zmiany

### GPS Quality Engine
- klasyfikacja jakości: EXCELLENT / GOOD / FAIR / POOR / SEARCHING,
- accuracy-aware filtering,
- filtr błędnych skoków / teleportów,
- walidacja timestampów i starych próbek,
- minimalny ruch dla ograniczenia szumu pozycji,
- wspólny model punktu dla Web GPS i Android Fused Location.

### Auto Pause
- wykrywanie postoju po kilku sekundach stabilnego braku ruchu,
- automatyczne przejście do pauzy,
- automatyczne wznowienie po wykryciu ruchu,
- ręczna pauza nadal działa niezależnie.

### Metryki
- moving time,
- średnia prędkość,
- dokładniejsze splity,
- odfiltrowane segmenty GPS,
- ograniczenie absurdalnych prędkości,
- przewyższenie oparte o poprawne segmenty.

### Analiza treningu
- 8-tygodniowa seria kilometrażu,
- trening load,
- recovery hint,
- regularność,
- najlepsze tempo,
- 7/30 dni.

### Health Connect
- natywny plugin Android,
- sprawdzanie dostępności,
- żądanie uprawnień przez oficjalny PermissionController,
- zapis sesji treningowej,
- zapis dystansu,
- odczyt tętna z okresu treningu,
- ekran uzasadnienia uprawnień.

### UI / UX
- wskaźnik jakości GPS z accuracy w metrach,
- stan auto-pause,
- wskaźnik offline,
- live KPI podczas treningu,
- wykres kilometrażu w profilu,
- karta Health Connect.

## Nadal celowo NIE oznaczono jako ukończone
- map matching zależny od zewnętrznego routingu,
- live BLE heart-rate sensor,
- automatyczna synchronizacja serwerowa,
- test terenowy na fizycznym urządzeniu.

Te elementy wymagają konkretnego sprzętu / providera / backendu i nie powinny być udawane w kodzie jako gotowe.
