# RunnerOS V1.0

## Implemented
- Offline-first sync queue with retry state and configurable API endpoint.
- PostGIS backend contract + initial activity/segment schema.
- Local segment detection engine using GPS geometry tolerance.
- Route-provider abstraction for future OSRM/Valhalla/GraphHopper or own routing backend.
- Android BLE Heart Rate plugin: scan, connect, notifications, BPM events.
- BLE permissions and plugin registration.
- Profile: Sync status + BLE HR controls.
- Existing GPS/Health Connect/analytics retained.

## Validation boundary
- TypeScript source is structured for `npm run typecheck`.
- Full web and Android build still requires installed Node/Gradle dependencies and a real device for GPS/BLE validation.
- BLE scan/connect is implemented for Android, but sensor interoperability must be tested against real HR straps.
