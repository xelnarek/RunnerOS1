# RunnerOS V1.1

## Cel
Przejście z trackera treningowego do aplikacji z warstwą społecznościową, wyzwaniami i osobistą heatmapą.

## Dodano
- Explore jako piąta sekcja głównej nawigacji.
- lokalny feed aktywności na podstawie rzeczywistej historii użytkownika.
- udostępnianie ostatniego treningu przez Web Share API z fallbackiem do schowka.
- osobista heatmapa gęstości punktów GPS.
- wyzwanie 100 km / miesiąc.
- wyzwanie regularności 8 treningów / 30 dni.

## Status
Warstwa społecznościowa jest jeszcze lokalna. Prawdziwi znajomi, kudos, komentarze i rankingi wymagają backendu użytkowników oraz autoryzacji.
