# RunnerOS V1.2

## Dodano
- warstwę API client dla auth/feed/activity/follow
- model lokalnego follow/unfollow
- ekran społeczności z wyszukiwaniem i obserwowaniem
- backend schema: users, follows, kudos, comments, activities, segments
- API contract dla JWT, feedu, geospatial, heatmap i routingu
- zabezpieczenia i wymagania idempotentnej synchronizacji

## Zachowano
GPS, Android foreground location, BLE HR, Health Connect, IndexedDB, offline queue, segment engine, routing abstraction, Explore i premium UI.

## Ważne
Frontend ma lokalny fallback społecznościowy; produkcyjny feed wymaga `VITE_API_URL` i wdrożonego backendu zgodnego z `API_CONTRACT_V1.2.md`.
