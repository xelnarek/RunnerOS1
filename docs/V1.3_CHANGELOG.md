# RunnerOS V1.3

## Backend made executable
- Added a runnable Node API under `server/`.
- Register/login with PBKDF2 password hashing and HS256 access JWT.
- Authenticated `/v1/me`.
- Activity upsert with PostGIS LineString.
- Idempotent offline sync endpoint.
- Follow/unfollow and user search.
- Personalized feed.
- Personal heatmap geometry aggregation.
- CORS, JSON parsing, input limits and parameterized PostgreSQL queries.

## Frontend API
- Added register/login/search/heatmap API methods.
- Preserved offline-first storage and existing GPS/Android/Health Connect/BLE layers.

## Production caveats
- Use a strong `JWT_SECRET` and TLS.
- Add refresh-token rotation, rate limiting, email verification, password reset and object storage before public launch.
- Run PostgreSQL with PostGIS and apply `server/schema.sql`.
