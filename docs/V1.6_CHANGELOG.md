# RunnerOS V1.6 — Release Candidate tooling

V1.6 jest etapem „buildable/testable RC”. Nie udaje fizycznego testu urządzenia.

## Dodano
- spójne wersjonowanie 1.6.0 / Android versionCode 16;
- `npm run preflight` — kontrola kompletności projektu, manifestu i wersji;
- `npm run verify:server` — uruchomienie API bez bazy i kontrola `/health` + auth guard;
- `npm run verify` — statyczna weryfikacja skryptów serwera i narzędzi;
- Docker Compose uruchamia DB + API razem;
- healthcheck API sprawdza `/health`;
- GitHub Actions CI: typecheck, tests, build, migracja PostGIS i smoke API;
- frontendowy badge wersji V1.6.

## Granica testów
Pełny Android APK/AAB i terenowy GPS nadal wymagają Android SDK, Gradle cache, zależności oraz fizycznego telefonu. V1.6 dostarcza automatyzację i preflight, ale nie fabrykuje wyniku testu sprzętowego.
