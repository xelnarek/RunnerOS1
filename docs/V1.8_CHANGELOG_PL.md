# RunnerOS V1.8 — UI + Audio

## Wizualne
- odświeżony system kart, CTA i nawigacji;
- poprawiona hierarchia KPI na ekranie biegu;
- 6-elementowa dolna nawigacja poprawiona do siatki 6 kolumn;
- lepsze stany hover/active/focus;
- dopracowane odstępy, kontrast i responsywność;
- spójniejszy wygląd premium bez kopiowania brandingu Stravy.

## Audio
- silnik Web Speech API z kolejką FIFO;
- brak nakładania komunikatów; komunikat priorytetowy może przerwać bieżący;
- polski głos preferowany automatycznie;
- komunikaty START / PAUZA / WZNÓW / KONIEC;
- komunikaty kilometrowe ze średnim tempem;
- ostrzeżenie przy słabym GPS;
- ustawienia głośności, głosu i rodzajów komunikatów;
- test głosu w profilu;
- ustawienia zapisywane lokalnie.

## Wydajność
- progi kilometrowe audio liczone inkrementalnie, bez przeliczania całej historii GPS dla każdego punktu.

## Ograniczenie
Web Speech API jest zależne od implementacji WebView/urządzenia. Dla finalnego Androida rekomendowane jest późniejsze spięcie z natywnym Android TTS, jeśli wymagane będą gwarantowane komunikaty przy wygaszonym ekranie.
