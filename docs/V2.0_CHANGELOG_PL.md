# RunnerOS V2.0

## Cel
Przejście z tracker'a i listy funkcji do zintegrowanego silnika treningowego.

## Nowe moduły
- Workout Engine: etapy, interwały, rozgrzewka, tempo, recovery, cooldown.
- Readiness Score: prosty model gotowości oparty o ostatnie obciążenie i czas regeneracji.
- Adaptive Recommendation: wybór jednostki na podstawie historii i celu.
- Race Predictor V2.0: prognoza 5K/10K/HM z confidence.
- Goal Engine: aktywny cel dystans/czas/termin.
- Gear model V2: trwałe pary butów, przebieg i limit.
- Native Android TTS: komunikaty głosowe przez TextToSpeech z transient ducking.
- Audio Engine: preferowanie natywnego TTS na Androidzie, fallback do Web Speech.

## Zachowane
GPS / foreground service / IndexedDB / offline sync / Health Connect / BLE HR / PostGIS / social / PWA.
